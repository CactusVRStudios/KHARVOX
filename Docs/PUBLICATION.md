# Contenu des téléchargements

## Sources

`DOOM-VR-PLUS-v1.4.1-sources.zip` contient le code du fork, la documentation,
les tests et les instructions des agents, sans `.git`, build, cache, journal,
préférence utilisateur ni identifiant. Les sous-modules restent des références
Git à initialiser séparément si nécessaire.

Les ressources déjà publiées avec le dépôt upstream gardent leur provenance.
Les deux fichiers de morphs ajoutés sont calculés depuis ses mains originales,
pas depuis les modèles Praetor du jeu.

## Paquet Windows complet

`DOOM-VR-PLUS-v1.4.1-complet.zip` contient le launcher Avalonia compilé, son
hôte, la couche VR, les loaders et bridges, les shaders SFS/AER, les profils
validés, le HUD, le visuel de grenade et les modèles Praetor nécessaires aux
prises à une et deux mains. Le cadre GIF est embarqué. Français par défaut ;
anglais disponible et mémorisé.

Le paquet ne contient aucun exécutable DOOM, aucune sauvegarde, aucun réglage
utilisateur et aucun chemin propre à la machine de développement. Chaque
joueur doit disposer de sa propre installation légitime de DOOM (2016).

## Éléments de développement non publiés

Les scènes Blender de travail, captures, journaux, exports intermédiaires et
fichiers de provenance contenant des chemins locaux restent hors des ZIP. Le
paquet distribue uniquement les fichiers runtime retenus après validation.
