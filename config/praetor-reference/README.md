# Profils Praetor de référence

Copies des configurations du dernier paquet local validé, sans changement
de matrices, d'échelle, de points d'accroche ni de paramètres de geste.
Elles ne sont pas installées automatiquement par CMake ou par le ZIP launcher.

**Les modèles GLB correspondants et leurs textures ne sont pas distribués.**
Les empreintes FNV64 de ces configurations identifient les ressources validées.
Ne pas les contourner et ne pas copier ces profils dans un runtime dont les
assets ne correspondent pas. Les poses de doigts baked dans les GLB ne peuvent
pas être recréées à partir de ces seules configurations.

Les chemins sont relatifs au runtime et ne contiennent pas de chemin personnel.
Le HUD reprend la pose manuelle finale ; ne pas réappliquer l'ancien espacement.
La grenade est une tenue visuelle, pas une libération native synchronisée.
